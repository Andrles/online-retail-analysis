# Анализ продаж интернет-магазина

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Andrles/online-retail-analysis/blob/main/analysis.ipynb)

Ноутбук можно запустить в браузере через кнопку выше — установка Python не требуется.

## Цель проекта

Исследовать транзакции интернет-магазина и ответить на практические вопросы бизнеса:

- какие товары и страны приносят больше всего выручки;
- как меняются продажи во времени;
- какие клиенты особенно ценны;
- какие действия могут повысить выручку.

## Данные

Использован открытый набор данных **Online Retail** от UCI Machine Learning Repository. В нём содержатся транзакции британского интернет-магазина за 2010–2011 годы. При первом запуске скрипт сам скачает исходный Excel-файл из UCI в папку `data/`.

Перед анализом из данных были удалены отменённые заказы, позиции с нулевой или отрицательной ценой и количеством, а также строки без идентификатора клиента и описания товара.

## Инструменты

Python, pandas, matplotlib, seaborn, openpyxl.

## Результаты

После очистки данных в анализ вошли **397 884** товарные позиции из **18 532** заказов.

| Метрика | Значение |
| --- | ---: |
| Общая выручка | £8,911,407.90 |
| Уникальные клиенты | 4,338 |
| Средняя сумма заказа | £480.87 |
| Доля Великобритании в выручке | 82.0% |

### Топ стран по выручке

2. Нидерланды — £285,446.34
3. Ирландия — £265,545.90
4. Германия — £228,867.14
5. Франция — £209,024.05

### Динамика продаж

Максимальная выручка наблюдалась в ноябре 2011 года — £1,161,817.38. Следующие по объёму месяцы — октябрь и сентябрь 2011 года. Это указывает на выраженный рост продаж перед новогодним сезоном.

## Рекомендации для бизнеса

- Планировать повышенные запасы ключевых товаров к осени и предновогоднему периоду.
- Активнее продвигать товары-лидеры: они уже подтверждают высокий спрос.
- Развивать продажи в Нидерландах, Ирландии, Германии и Франции: эти рынки наиболее перспективны после Великобритании.
- Так как основная часть выручки зависит от Великобритании, следует снижать риск концентрации за счёт международного роста.
